# VOTACIÓN ERM 2026 – LIMA

Proyecto académico de simulación de una experiencia de votación digital inspirada en la información pública de las Elecciones Regionales y Municipales 2026.

## Archivos principales

- `index.html` → estructura de la aplicación.
- `style.css` → diseño, colores, ventanas, tarjetas y versión responsive.
- `script.js` → lógica de identificación, selección, voto, confirmación, resultados, geolocalización y ventanas informativas.

## Carpetas

- `candidatos/` → imágenes proporcionadas para la simulación.
- `recursos/` → imagen de referencia ERM 2026 y cédula proporcionada.

## Cómo ejecutar

1. Descomprime el ZIP.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` con Chrome o utiliza Live Server.
4. Para la geolocalización, acepta el permiso del navegador.

## Importante

Este proyecto es una **SIMULACIÓN ACADÉMICA**. No es un sistema oficial de ONPE, no registra votos reales y no valida el padrón electoral.

El botón “SEPA DÓNDE VOTAR” dirige a la consulta oficial de ONPE. La disponibilidad de esa consulta depende de la plataforma oficial.

Fuente oficial del proceso: https://erm2026.onpe.gob.pe/
